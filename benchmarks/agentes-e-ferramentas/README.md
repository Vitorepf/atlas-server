# Agentes e Ferramentas

Benchmarks de **diálogo agêntico com uso de ferramentas** — o agente conversa e
chama ferramentas para cumprir uma tarefa (ex.: atendimento). Não é engenharia de
código; é orquestração de ferramentas em conversa.

> **Estado do braço "com Atlas" aqui:** em aberto, mesma razão do intuito
> Conhecimento — exige um runtime governado de resposta/agente (cérebro Atlas com
> Hermes por dentro), não o `atlas:cli:dev` de código. Até lá, **"não medido"**
> para o Atlas, nunca Hermes cru disfarçado. Ver `docs/rivals-warroom.md`.
