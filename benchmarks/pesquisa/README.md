# Pesquisa / agente geral

O agente pesquisa, raciocina em cadeia e usa ferramentas para achar uma resposta
do mundo real. Roda **nativo no Mac** (a correção é por match da resposta final).
Detalhe em [`../LISTA-COMPLETA.md`](../LISTA-COMPLETA.md).

## Candidatos nativos a integrar
- **GAIA** ✅ — 466 perguntas reais que exigem raciocínio, web browsing,
  multimodalidade e uso de ferramentas em cadeia. A correção é match exato da
  resposta final (roda nativo); o agente precisa de acesso real a ferramentas
  (web/arquivos) para resolver.

> Cobertura de pesquisa/browsing ainda é rasa (só GAIA). Se quiser aprofundar
> (agentes de deep-research, browsing), peça uma varredura dedicada.
