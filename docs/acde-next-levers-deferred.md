# ACDE next-levers — honest deferral record

Companion to `acde-exponential-architecture-levers.md`. After the 4 curve-bending flywheels and the
ship-now foundations were delivered, a multi-agent adversarial discovery pass produced 31 next-lever
candidates; 5 were killed outright and 26 survived. Of the survivors, the operator decided (2026-06-16) to
**ship the 8 genuinely-valuable LINEAR levers** and to **honestly defer the bounded remainder with written
reasons** rather than grind them for literal completeness — exactly the anti-theater discipline the loop
enforces on itself.

This file is that written record. Each deferred lever is REAL (it named a true seam), but its live value is
bounded for the reason stated. None is abandoned; each can be promoted when its precondition holds.
