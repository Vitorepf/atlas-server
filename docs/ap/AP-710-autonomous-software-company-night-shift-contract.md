# AP-710 Autonomous Software Company Night Shift Contract

## Decision

Atlas Autonomous Software Company Night Shift is a governed operational loop
inside the existing Autonomous Software Company Runtime. It is not a new OS, not
a replacement for AAEOS, not a replacement for Self-Directed Evolution and not a
shortcut to World Action.

## Mandatory Progression

Night Shift must prove itself on Atlas before operating any external company or
product repository.

```text
NS-v1 = Atlas Internal Night Shift only.
NS-v2 = Authorized External Company Night Shift, unlocked only after v1 evidence.
```

The first production-grade version must run on Atlas repositories. External
company operation, including BlackInk, is forbidden until the operator approves a
promotion receipt from v1 to v2.

## Authority Mapping

| Capability | Existing owner |
|---|---|
| Autonomous software company orchestration | Atlas Autonomous Software Company Runtime |
| Gap/spec proposal | Self-Directed Evolution Layer |
| Implementation execution | Atlas Dev, Forge, Self-Construction OS |
| Branch/worktree isolation | Programming Governance + Forge workspace contracts |
| Evidence, receipts and certification | Evidence Certification Runtime |
| Outcome feedback | Reality Outcome Gates + ASRE/AEMOR |
| External company authorization | Domain Runtime Contract + operator mandate |

## Forbidden

- Running v1 against BlackInk or any external company repository.
- Merging, deploying or pushing automatically.
- Accessing secrets, production credentials or external side effects.
- Creating a parallel software-company runtime, proposal registry or execution
  engine.
- Treating an overnight implementation attempt as approved without operator
  review.

## Acceptance

- Canonical Night Shift doc exists and declares v1 internal-first.
- The doc maps every capability to an existing owner.
- v2 has explicit promotion gates and cannot be implied by v1.
- Morning Inbox, branch sandbox, evidence pack and rollback are mandatory.
- docs-health and architecture validation pass.
